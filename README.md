---

OnDev entwickelt Anwendungen und Apps – von der ersten Skizze über den Prototyp bis zum laufenden Betrieb.
Unsere Kunden sehen Zwischenstände früh, probieren sie aus und besprechen sie mit uns, bevor etwas produktiv geht.

### Was wir bauen

| | |
|---|---|
| 🟧 **Anwendungen** | Fachanwendungen für den Betriebsalltag: Auftrag, Disposition, Zeiterfassung, Abrechnung |
| 🟦 **Apps** | für Handy und Tablet – offlinefähig, mehrsprachig, ohne App-Store, direkt im Browser |
| 🟧 **Schnittstellen** | Anbindung an Buchhaltung, Lohnabrechnung, Warenwirtschaft und Website |
| 🟦 **Betrieb und Pflege** | Hosting, Aktualisierung, Sicherung und Weiterentwicklung |

### Womit wir arbeiten

`PHP / Laravel` · `TypeScript / React` · `PWA` · `Tauri` · `MariaDB` · `REST` · `WordPress` · `Hosting in der EU`

### Wie wir arbeiten

- **Früh zeigen statt lange beschreiben** – jeder Zwischenstand läuft in einer eigenen Vorführumgebung.
- **Getestet, bevor es ausgeliefert wird** – automatische Prüfungen in jedem Bau.
- **Daten bleiben in Europa** – europäische Anbieter und offene Standards bevorzugt.
